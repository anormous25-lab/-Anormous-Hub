# ANORMOUS V1

Mobile-first "Test → Train → Improve" prototype.

## Included
- Reaction test
- Memory test
- Tap accuracy test
- Typing test
- Local best-score storage
- No account
- No backend
- No external API required

## Run locally
Open `index.html` in a browser, or use VS Code Live Server.

## Deploy free
Cloudflare Pages can deploy this as a static site. Connect the repository, use no build command / a static build, and publish the folder containing `index.html`.
